# 手动测试清单

## 启动和首页

- 首次启动出现示例持仓和关注股票。
- 首页显示总市值、当日盈亏、累计盈亏、持仓数量。
- 首页“异动提示”展示监控预警，而不是持仓列表。
- 预警按严重、警告、提示排序，同级按时间从新到旧排序。
- 点击“全部已读”后，未读数量清零。
- 已读预警变为弱化灰色样式。
- 点击“清除已读”后，已读预警从列表移除。
- 点击“立即检查”后触发一次监控检查。
- Android 13+ 未授权通知时，首页显示“开启通知”入口。
- 后台监控生成严重/警告预警时发送系统通知。
- 后台监控生成提示级别预警时不发送系统通知，但预警正常入库。
- 点击系统通知后进入对应预警详情；预警已被清理时回到首页。
- 空网络环境下 App 不崩溃，并保留本地缓存数据。

## 内置个人数据

- 将 `docs/personal_portfolio.example.json` 复制为 `app/src/main/assets/personal_portfolio.local.json` 后安装，空库首次启动会导入持仓、关注股和监控配置。
- 本地数据库已有持仓或关注股时，重启 App 不会用 JSON 覆盖已有数据。
- JSON 缺少可选字段时使用默认值或代码推断。
- JSON 格式错误时不清库，首页显示导入失败提示。

## 关注列表

- 持仓股票和关注股票合并显示。
- 表格支持横向滚动。
- 未持仓关注股的持仓字段显示 `--`。
- 有行情时，未持仓关注股仍展示现价。
- 关注后涨幅在存在基准收盘价和最新价时正确显示。
- 预警数量按该股票已保存预警总数展示。
- 删除关注股后，该股票不再出现在关注列表。
- 删除关注股后，该股票已保存预警同步删除。

## 个股工作台

- 点击关注列表中的股票进入个股工作台。
- 页面展示行情、持仓指标、关注信息、监控状态、预警记录和操作记录。
- 点击“监控设置”可以进入该股票的监控配置页。
- 点击“清除已读”只清除当前股票的已读预警。
- 预警卡片点击后进入预警详情，并标记为已读。

## 交易操作

- 点击“添加操作”进入买入/卖出表单。
- 数量和价格为空、非数字或小于等于 0 时不能保存。
- 手续费按成交额万一展示。
- 买入后生成操作记录，并同步增加持仓数量。
- 买入后成本价按原成本金额、买入金额和手续费重算。
- 卖出超过持仓数量时保存失败。
- 卖出后生成操作记录，并记录已实现盈亏。
- 部分卖出后持仓数量减少，成本价不变。
- 全部卖出后持仓删除。

## 持仓编辑

- 新增持仓必须填写 6 位代码、名称、数量、成本价、现价。
- 输入 6 位代码后自动查询股票名称和行情。
- 查询失败时允许手动输入名称和现价。
- 编辑持仓后首页汇总刷新。
- 删除持仓后首页和关注页刷新。

## 监控设置

- 可以打开单只股票监控设置。
- 可以启用或暂停监控。
- 可以调整成本、涨跌幅、量能、均线、RSI、跳空和动态止盈相关阈值。
- 保存后返回页面，后续检查使用新配置。

## OCR 截图导入

- 点击“选择截图”能打开系统图片选择器。
- OCR 成功后展示原文和候选持仓。
- 可以修改识别出的代码、名称、数量、成本价、现价。
- 确认导入后，候选持仓进入正式持仓列表。
- 模糊截图或无持仓字段时显示识别失败或无结果提示。

## 每日复盘

- 持仓存在时能生成复盘文案。
- 复盘文案包含组合表现、主要贡献、主要拖累、异动提示和明日计划。
- 可以保存复盘。
- 可以复制复盘文案和 AI 润色 Prompt。
