# 项目说明

## 项目定位

持仓复盘 App 面向个人投资者，帮助用户把日常持仓记录、关注观察、行情检查、预警处理、交易操作和复盘记录统一到一个本地应用里。应用不接入券商交易系统，不做自动下单，主要用于个人记录、辅助观察和复盘整理。

## 用户场景

用户每天打开应用后，可以先在首页查看组合整体表现和最新异动预警；再进入关注页查看持仓和关注股票的横向表格；点击单只股票进入工作台，查看该股票的行情、持仓、关注信息、预警和操作记录。需要录入交易时，可以在工作台添加买入或卖出操作，应用会自动同步持仓。

## 核心闭环

```text
记录持仓 / 添加关注
        ↓
刷新行情 / 后台检查
        ↓
生成预警 / 查看个股工作台
        ↓
记录买卖操作 / 同步持仓
        ↓
生成每日复盘 / 保存记录
```

## 主要能力

- 本地持仓管理和组合收益计算。
- 关注股票表格和关注后涨幅计算。
- 股票监控预警和已读清理。
- 个股工作台聚合行情、持仓、关注、预警和操作。
- 买入/卖出操作记录，并自动同步持仓。
- 券商截图 OCR 识别和人工确认入库。
- 每日复盘文案和 AI 润色 Prompt。

## 技术特点

- 使用 Compose 构建声明式 UI。
- 使用 StateFlow 管理页面状态。
- 使用 Room 保存结构化数据，并维护迁移 schema。
- 使用 Repository 隔离本地数据、远程行情和业务层。
- 使用 WorkManager 执行后台监控。
- 使用 ML Kit 降低截图导入的手动录入成本。

## 适用边界

- 适合个人记录、观察和复盘。
- 预警结果只作为辅助信息。
- 行情接口稳定性依赖外部服务。
- 不包含账户登录、真实交易、自动下单和云同步。
