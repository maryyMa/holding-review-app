# Vibe Coding 提示词记录

## 需求拆解

```text
我要做一个 Android 持仓复盘 App，用于面试展示。目标用户是个人投资者。功能包括持仓记录、关注股票、A 股行情刷新、异动提示、上传券商截图 OCR 导入持仓、每日复盘文案生成和复制导出。请帮我拆 MVP、页面、数据模型和边界。
```

## 架构设计

```text
请基于现代 Android 技术栈设计架构：Kotlin、Jetpack Compose、MVVM、StateFlow、Room、Hilt、Retrofit/OkHttp、WorkManager、ML Kit OCR。要求说明 UI 层、业务层、数据层、依赖注入、后台任务和测试策略。
```

## 代码生成

```text
请生成一个 Kotlin Android Demo 的核心代码结构，包括 Room 实体和 DAO、Repository、行情 RemoteDataSource、OCR 解析 UseCase、收益计算 UseCase、复盘生成 UseCase、Compose 首页和 ViewModel。要求每层职责清晰，避免把业务逻辑写在 UI 里。
```

## 代码审查

```text
请像 Android 面试官一样审查这个项目，重点检查 Compose 状态管理、Room 数据设计、网络失败回退、OCR 识别确认流程、收益计算边界、Hilt 注入和可测试性。
```

## 面试表达

```text
请帮我把这个持仓复盘 App 包装成 2 分钟面试项目讲解，突出 Kotlin 现代 Android 架构、AI 辅助开发、端侧产品闭环、OCR、行情刷新和复盘生成。
```
